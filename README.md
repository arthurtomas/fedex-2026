# Discover Your Inner Animal

Project created for FedEx Day 2026 - An interactive personality test that identifies which animal best represents your work style.

## How to Use

1. Open the `index.html` file in any modern browser
2. Enter your name
3. Answer 7 questions about your personality and work style
4. Discover which inner animal represents you!

## Animals Included

- 🦅 Eagle - Visionary and strategic
- 🦁 Lion - Courageous and leader
- 🐺 Wolf - Teamwork and loyalty
- 🐝 Bee - Hard work and productivity
- 🐰 Rabbit - Agility and creativity
- 🐕 Dog - Loyalty and friendship
- 🐱 Cat - Independence and curiosity
- 🐬 Dolphin - Intelligence and sociability
- 🦉 Owl - Wisdom and observation
- 🐻 Bear - Strength and protection
- 🐴 Horse - Energy and determination

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Features

- Modern and responsive interface
- Smooth animations
- Scoring system based on personality traits
- Works completely offline
- No need for server or database

## FedEx Day Presentation

This project demonstrates how to create an interactive and engaging experience using only basic web technologies. The personality analysis system maps responses to specific characteristics of each animal, generating personalized and positive results.
